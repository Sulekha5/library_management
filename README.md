# 📚 Library Management System (.NET Framework)

🚀 A complete **Library Management System** built using **.NET Framework**, designed to automate library operations like managing books, users, and transactions.
🎥 **Demo Video:** https://youtu.be/jfM4uSG0k2I

---

## ✨ Features

* User Authentication (Admin/User)
* Add / Update / Delete Books
* Issue & Return Books
* Track Borrowed Books
* Search Books
* Manage Members
* Maintain Records

---

## 🧠 Project Overview

This project digitizes library operations and replaces manual work with an automated system.

* Easy book management
* Fast search system
* Real-time tracking of issued books

---

## 🛠️ Tech Stack

* .NET Framework
* C#
* SQL Server
* WinForms / ASP.NET

## ⚙️ Installation & Setup

### 1. Clone Repo

```
git clone https://github.com/Sulekha5/library_management.git
```

### 2. Open in Visual Studio

* Open `.sln` file

### 3. Setup Database

* Configure connection string
* Run SQL scripts

### 4. Run Project

* Click ▶️ Start
